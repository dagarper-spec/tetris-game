# Bloques

Un juego de bloques arcade inspirado en los clásicos, construido con HTML, CSS y JavaScript sin dependencias de ejecución.

## Cómo jugar

Abre `index.html` en un navegador o publica el repositorio con GitHub Pages.

- **← / →**: mover la pieza
- **↑**: girar
- **↓**: bajar más rápido
- **Espacio**: caída rápida
- **P**: pausar o continuar
- **R**: empezar una partida nueva

En móvil, usa los botones táctiles bajo el tablero. Completa líneas para ganar puntos; la velocidad aumenta cada diez líneas. El récord se guarda localmente en el navegador.

## Archivos

- `index.html`: estructura y contenido
- `style.css`: diseño adaptable
- `game.js`: lógica, dibujo y controles
